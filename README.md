#  Pintia 字符粘贴器 

 - **一个专为 Pintia.cn (拼题A) 打造的防屏蔽粘贴脚本。**
 - **以“隐形打字机”的模式，完美绕过平台的复制粘贴限制与字数增量检测,且不需要给予网站读取剪切板的权限。**


## 📦 安装指南

 1. 确保你的浏览器已安装 **Tampermonkey (油猴)** 扩展(需要开启允许运行用户脚本)
 2. 点击[此处添加脚本](https://greasyfork.org/zh-CN/scripts/570245-pintia-%E5%AD%97%E7%AC%A6%E7%B2%98%E8%B4%B4%E5%99%A8)。
 3. 保存并启用脚本。

## 🚀 使用方法

操作完全符合你的直觉，没有任何学习成本：
 1. 在本地编辑器（如 VS Code）中写好代码，按下 `Ctrl + C` 复制。
 2. 回到 Pintia 做题页，鼠标**点击一下代码答题框**，让光标在里面闪烁。
 3. 按下 `Ctrl + V`，脚本会自动接管粘贴过程，以极快的速度将代码“敲”入屏幕。
 4. **中断操作**：在代码飞速输入的任何时刻，按下键盘左上角的 `ESC` 键即可紧急停止。
